Roblox game concept

Coin Yard

An original Roblox simulator. Collect coins, upgrade your tools, unlock new yards, and chase rebirths. The loop is proven, the game is not a copy of anyone else's game.

Status: Concept and Studio starter plan. It becomes a real Roblox game when it is built and published from Roblox Studio.

The loop, in 60 seconds

1. Spawn in a yard. Walk over coins to collect them.

2. Spend coins on a better collector, then a faster collector.

3. Unlock the next yard when the current one feels too easy.

4. Rebirth for a permanent multiplier, then do it faster next run.

5. Come back daily for a streak bonus and a new short goal.

Why this loop, and why not a dupe

Collect, upgrade, unlock, and rebirth is a generic game loop. No one owns that idea. What you cannot copy is another game's name, characters, art, music, maps, or code. The Instagram post that started this idea warned about exactly that: unauthorized browser versions of popular games get takedown notices from publishers.

Rule for this build: original name, original art, original maps, original music. Borrow the loop, never the IP.

How it makes money, inside Roblox only

  • Game Passes, one time purchase: 2x Coins, VIP Yard, Faster Start.
  • Developer Products, repeat purchase: small coin packs, skip a grind step. Price them so the grind still feels fair without paying.
  • Premium Payouts: Roblox pays for playtime from Premium members, on top of sales.
  • No outside Robux deals, no free Robux generators, no off-platform sales. Those are scams or rule violations, and they get accounts shut down.

The real cash-out math

Roblox only lets you cash out Earned Robux through Developer Exchange, called DevEx. Robux you bought yourself does not count.

Minimum to request a cash-out: 30,000 Earned Robux.

Standard rate, as of the latest check: $0.0038 per Earned Robux, so 30,000 Earned Robux is $114 before tax and any withholding.

Roblox takes 30% of Game Pass and Developer Product sales, so a 100 Robux sale leaves 70 Earned Robux. Price with that cut in mind, and check the current DevEx page in Creator Hub before you plan around a payout.

Eligibility also includes being 13 or older, a verified email, a DevEx portal account, and a tax form on file. Roblox decides eligibility when you apply, not before.

Build it in Roblox Studio, week one

Day 1. Open Roblox Studio, start a Baseplate, save it as Coin Yard. Build one yard, coin spawns, and a spawn point. Nothing else.

Day 2. Add leaderstats: Coins and Rebirths. Add the collect script below as a ServerScript in ServerScriptService.

Day 3. Add one shop: buy a better collector with coins. Test it with a friend, fix the bugs, then publish as a private test.

Day 4. Add the second yard, one rebirth button, and daily streak data. Keep it boring and working before you add pets, events, or cosmetics.

Day 5. Publish, post one Short showing the loop, and watch where players quit. Fix that spot first.

Starter script: collect coins

Put this in ServerScriptService. It gives every player a Coins leaderstat, and every coin part tagged "Coin" in the workspace gives 1 coin on touch, then respawns after 5 seconds.

-- Coin Yard starter, ServerScriptService
local Players = game:GetService("Players")
local CollectionService = game:GetService("CollectionService")

Players.PlayerAdded:Connect(function(player)
  local leaderstats = Instance.new("Folder")
  leaderstats.Name = "leaderstats"
  leaderstats.Parent = player
  local coins = Instance.new("IntValue")
  coins.Name = "Coins"
  coins.Value = 0
  coins.Parent = leaderstats
end)

local function giveCoin(part, player)
  local leaderstats = player:FindFirstChild("leaderstats")
  if not leaderstats then return end
  local coins = leaderstats:FindFirstChild("Coins")
  if coins then coins.Value += 1 end
  part.CanTouch = false
  part.Transparency = 1
  task.wait(5)
  part.CanTouch = true
  part.Transparency = 0
end

for _, part in CollectionService:GetTagged("Coin") do
  part.Touched:Connect(function(hit)
    local player = Players:GetPlayerFromCharacter(hit.Parent)
    if player then giveCoin(part, player) end
  end)
end
